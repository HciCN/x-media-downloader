# X-Media-Downloader (X/Twitter 批量媒体抓取与下载器)

> 🚀 **v1.1.0 重磅升级**：新增信息流单推文直接秒存、多图气泡选择、悬浮球自由拖拽吸附、内置沉浸式视频播放器！

基于对 **Plucker XBD** 逆向工程深度重构的独立、开源、无广告媒体抓取与下载利器，无需依赖外部付费第三方云端，所有抓取、解析与下载均在本地浏览器中直接完成。

---

## ✨ 核心功能与亮点

1. **推文操作栏内嵌即时下载（全新）**：
   - 自动在 X/Twitter 信息流每条推文底部操作栏（转推、点赞旁）注入专属下载图标。
   - **单图/单视频推文**：点击直接秒存最高清原图或最高码率 MP4，带打勾完成反馈。
   - **多图/多视频推文**：悬浮/点击弹出精致气泡菜单，可单独勾选下载某张，或一键「全部保存」。
2. **悬浮球自由拖拽与边缘吸附（全新）**：
   - 悬浮图标支持全屏任意拖拽摆放，智能吸附贴边，彻底告别遮挡原生发推与私信按钮。
   - 自动在本地存储记录拖拽坐标，页面刷新后依然保持在你指定的位置。
3. **内置视频与大图预览 Lightbox 播放器（全新）**：
   - 在面板媒体画廊中点击视频，直接唤出半透明沉浸式弹窗播放器，支持循环、全屏与一键单项下载，无需新开空白标签页。
4. **自动游标深度分页（Cursor Pagination）**：
   - 主世界截获 X 官方 GraphQL 接口（`UserMedia`/`UserTweets`），深度提取 `TimelineTimelineCursor (Bottom)`，自动向下迭代抓取，无漏网推文。
5. **最高画质无损媒体提取**：
   - **图片**：自动替换为最高无损分辨率（`?name=orig`）。
   - **视频 / GIF**：自动对推文中的 `video/mp4` 格式按 `bitrate`（码率）从大到小排序，优先提取画质最高的直链。
6. **Plucker 同款动态防封退避算法**：
   - 内置根据翻页深度的自适应阶梯随机等待机制（`By(p)`），抓得越多等待间隔越平滑，彻底避免触发 Twitter 429 速率限制或账号风险。
7. **多重下载与导出方案**：
   - **一键打包 ZIP**：内置离线 JSZip，自动以 `博主_推文ID_序号.jpg/mp4` 压缩打包下载，单次完成数百张图无需点击多次。
   - **原生多线程并发下载**（Chrome 扩展专属）：调用 Chrome 后台下载管理器，支持 1~10 线程并发后台高速保存。
   - **TXT 直链导出 / 一键复制**：支持导出 URL 清单，可无缝导入迅雷、IDM、Motrix、Aria2 或 wget。
   - **JSON 完整元数据导出**：导出推文正文、发推时间、原推 ID 及多媒体对应关系。

## 🛠️ 安装与使用教程（提供两种方式，任选其一即可）

### 方式一：Chrome / Edge 原生扩展安装（推荐，功能最全）

1. 打开 Chrome 或 Edge 浏览器，在地址栏输入并回车：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
2. 打开页面右上角的 **「开发者模式」** 开关。
3. 点击左上角的 **「加载已解压的扩展程序」**（Load unpacked）。
4. 在文件选择窗口中，选择本目录：
   ```
   F:\桌面文件\AI脚本\x-media-downloader
   ```
5. 打开任意 Twitter/X 页面（主页信息流或博主主页）：
   - 每条推文下方即可看到下载按钮。
   - 右下角有可自由拖拽的批量下载控制悬浮球。

---

### 方式二：油猴脚本安装（无需安装扩展，单文件即用）

如果你已经安装了 **Tampermonkey（篡改猴）** 或 **Violentmonkey（暴力猴）** / **ScriptCat（脚本猫）**：

1. 打开位于根目录的脚本文件：
   ```
   F:\桌面文件\AI脚本\X批量媒体下载器.user.js
   ```
2. 打开 Tampermonkey 仪表盘 -> **「实用工具」** -> **「导入」** 选择该文件，或者新建脚本将文件内容全选复制粘贴进去保存。
3. 刷新任何 X/Twitter 个人主页即可直接唤出控制面板和推文一键下载图标！
