# X-Media-Downloader (X/Twitter 批量媒体抓取与下载器)

> 🚀 **v1.3.0 重磅升级**：
> - **无预览纯净侧边栏**：侧边悬浮面板全面轻量化，移除拥挤易卡顿的微缩图列表，专注显示批次抓取进度与控制，一键直达大屏控制台；
> - **全量集中至 Web 总控制台全景预览**：所有大图/视频全屏高清瀑布流浏览；
> - **直达原推文超链接**：控制台画廊卡片悬浮遮罩、推文流分组卡片以及沉浸式 Lightbox 播放器内均配备 **「在 X 查看原推文 ↗」** 快捷跳转直链，一键回溯推文现场！

基于对 **Plucker XBD** 逆向工程深度重构的独立、开源、无广告媒体抓取与下载利器，无需依赖任何外部付费第三方云端，所有抓取、解析、存储与下载均在本地浏览器中直接完成。

## ✨ 核心功能与亮点

### 1. 🎛️ 独立大屏 Web 总控制台（全新升级 v1.3.0）
- **Plucker XBD 同款架构**：通过点击浏览器右上角扩展图标，或点击悬浮面板的 **「进入 Web 总控制台预览与查看原推 ↗」**，即可随时进入全屏专属管理后台 (`dashboard.html`)。
- **直通原推文链接（原推回溯）**：
  - **媒体平铺画廊**：鼠标悬停任意媒体卡片，即可浮现推文文本摘要与蓝色的 **「查看原推 ↗」** 按钮；
  - **推文分组卡片流**：将同一推文的媒体完整聚合，展示推文正文、推文 ID、发布时间以及 **「在 X 查看原推文 ↗」** 链接，支持针对该推文一键批量下载；
  - **沉浸式 Lightbox 播放器**：预览大图或播放高码率视频时，居中展示原推文本，并提供一键跳转至 X 官方原推文地址 (`https://x.com/i/status/{tweetId}`)。
- **本地离线任务引擎**：利用 `chrome.storage.local` 存储历史抓取任务与下载进度，数据 100% 留存在本地，保护隐私，无须任何后端服务器。
- **任务概览与巨幅进度看板**：清晰展示博主头像、昵称、抓取状态、四宫格核心指标（媒体总数、图片数、视频数、已下载数）及实时动态进度条。
- **双视图自由切换**：支持在 **🖼️ 媒体平铺画廊** 与 **💬 推文分组卡片流** 之间无缝切换。
- **个性化设置面板**：支持自定义并发下载线程数（1~10）、下载目录格式、文件命名模板及是否默认过滤转推。

### 2. 🪶 极致纯净轻量的侧边浮动面板
- 告别在狭小悬浮侧边栏堆叠上百张媒体缩略图导致的卡顿与内存溢出；
- 侧边栏专注呈现：当前博主名片、实时抓取批次状态、动态进度条、抓取数量限制与过滤条件、一键归档并前往 Web 控制台。

### 3. 🎯 媒体自由多选与按需打包
- **复选框与视觉选中态**：画廊中每张媒体均自带独立复选框，选中时带高亮边框标识。
- **快捷选择工具栏**：支持 **「全选」**、**「全不选」**、**「反选」**，并实时显示已选/总数（如 `已选 12 / 85`）。
- **按需打包下载**：
  - 点击 **「打包所选为 ZIP (N)」**：仅将你勾选的心仪图片或视频打包成压缩包下载。
  - 点击 **「下载所选」**：通过 Chrome 扩展后台多线程下载所选项目。
  - 点击 **「复制所选直链」**：仅复制勾选项目的直链到剪贴板，方便导入下载软件。

### 4. ⚡ 信息流推文操作栏内嵌即时下载
- 自动在 X/Twitter 信息流每条推文底部操作栏（转推、点赞旁）注入专属下载图标。
- **单图/单视频推文**：点击直接秒存最高清原图或最高码率 MP4，带绿色打勾视觉反馈。
- **多图/多视频推文**：悬浮/点击弹出精致气泡菜单，可单独点击下载某一张，或一键「全部保存」。

### 5. 🧲 悬浮球自由拖拽与边缘吸附
- 悬浮图标支持全屏任意拖拽摆放，智能吸附贴边，彻底告别遮挡原生发推与私信按钮。
- 自动在本地存储记录拖拽坐标，页面刷新后依然保持在你指定的位置。

### 6. 🔄 自动游标深度分页（Cursor Pagination）
- 主世界截获 X 官方 GraphQL 接口（`UserMedia`/`UserTweets`），深度提取 `TimelineTimelineCursor (Bottom)`，自动向下迭代抓取，无漏网推文。

### 7. 💎 最高画质无损媒体提取
- **图片**：自动替换为最高无损分辨率（`?name=orig`）。
- **视频 / GIF**：自动对推文中的 `video/mp4` 格式按 `bitrate`（码率）从大到小排序，优先提取画质最高的直链。

### 8. 🛡️ Plucker 同款动态防封退避算法
- 内置根据翻页深度的自适应阶梯随机等待机制（`By(p)`），抓得越多等待间隔越平滑，彻底避免触发 Twitter 429 速率限制或账号风险。

### 9. 🌊 批次流式流水线与推文分组视图（全新优化）
- **官方游标分块契合机制**：Twitter 官方 API 采用 GraphQL 分块传输（一次下发 20 条推文，含 20~50+ 媒体），翻到更底部时通过 `Bottom Cursor` 重新追加几十条。
- **DocumentFragment 高性能流水线挂载**：针对批次几十条媒体同时到达的特性，采用批量微任务流水线挂载与 $O(1)$ 增量状态绑定，即使抓取上千张图也丝滑无卡顿。
- **批次动态浮动气泡动效**：翻到底部触发新批次时，悬浮球实时浮现高亮绿色的 `+N 媒体` 动态气泡与批次标记（`第 N 批`），捕获过程一目了然。
- **双视图自由切换**：
  - **🖼️ 媒体平铺**：紧凑大图画廊，适合快速全景浏览与多选打包。
  - **💬 推文分组（Group by Tweet）**：将同一推文的套图聚合在推文卡片中，展示推文正文与发布时间，支持对单条推文一键全选或一键下载全部媒体！

## 🛠️ 安装与使用教程（提供两种方式，任选其一即可）

### 方式一：Chrome / Edge 原生扩展安装（强烈推荐，功能最全）

1. 打开 Chrome 或 Edge 浏览器，在地址栏输入并回车：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
2. 打开页面右上角的 **「开发者模式」** 开关。
3. 点击左上角的 **「加载已解压的扩展程序」**（Load unpacked）。
4. 在文件选择窗口中，选择本目录：
   ```
   F:\桌面文件\AI脚本\x-media-downloader
   ```
5. 安装完成后：
   - 点击浏览器右上角扩展栏中的 **X-Media-Downloader 图标**，即可直接打开 **Web 独立总控制台**。
   - 浏览任意 Twitter/X 页面，每条推文下方即可看到下载按钮；右下角悬浮球可随时呼出悬浮面板。

---

### 方式二：油猴脚本安装（无需安装扩展，单文件即用）

如果你已经安装了 **Tampermonkey（篡改猴）** 或 **Violentmonkey（暴力猴）** / **ScriptCat（脚本猫）**：

1. 打开位于根目录的脚本文件：
   ```
   F:\桌面文件\AI脚本\X批量媒体下载器.user.js
   ```
2. 打开 Tampermonkey 仪表盘 -> **「实用工具」** -> **「导入」** 选择该文件，或者新建脚本将文件内容全选复制粘贴进去保存。
3. 刷新任何 X/Twitter 个人主页即可直接唤出控制面板、推文一键下载图标及多选打包功能！
