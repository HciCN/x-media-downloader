🚀 方案一：电脑无线局域网串流 (手机扫码即看，0 占手机内存)
强烈推荐
电脑上抓取的高清视频动辄几百 MB 甚至数 GB，将其逐个复制到安卓手机极易造成手机存储告急。通过本功能，电脑直接充当流媒体服务器，手机通过 Wi-Fi 无线秒播！
  1. 双击运行插件根目录下的 start_remote_server.bat 启动脚本；
  2. 确保安卓手机和电脑连接在同一个家庭 Wi-Fi 下；
  3. 在下方输入电脑的局域网 IP（脚本窗口启动时会直接打印显示），生成访问直达链接；
  4. 在安卓手机浏览器（Chrome / Edge / 夸克 / 自带浏览器）中直接打开链接，视频支持自由拖动进度条！

📦 方案二：独立安卓离线推文阅读单页 (无需电脑，手机随时离线刷)
随身便携
前往任务看板点击 「📱 导出安卓离线单页 (HTML)」，系统将为你一键生成包含所有推文文本、发推时间、原推链接和高清多图的轻量离线网页单文件。
  • 在线 CDN 秒播模式：无需把视频文件拷入手机，手机只需打开该 HTML，通过原图和最高码率 MP4 官方 CDN 直链即可高清畅快观看；
  • 完全离线模式：将下载的图片与视频文件（或 ZIP 解压后）与 HTML 放入同一文件夹，手机无网断网也能完整离线浏览；
  • 仿官方 App 体验：深黑沉浸夜间模式、网格拼图、全屏手势缩放、原生播放器与推文关键词快速检索。
🌐 方案三：公网异地远程观看 (出门在外，5G 无线访问家里电脑)
如果你不在家里（使用蜂窝移动网络），推荐使用以下任一免费工具穿透连接电脑：
  • Tailscale (强烈推荐)：电脑和安卓手机分别安装 Tailscale 登录同一账号，直接使用手机浏览器访问电脑的 http://100.x.x.x:8080/dashboard.html；
